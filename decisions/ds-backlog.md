# Design System Backlog

Design system component and token tasks that come out of spec and audit work but are executed separately so the flow is not blocked. The `ui-architect` proposes the entries; a human approves them before they are written.

## Entry format

```
## N. Short title
- Origin: where it came up (spec, page, audit) and date
- Evidence: specific files or nodes
- Pending decision: the question to resolve
- Interim: how it is documented in the meantime
- Owner: person or role
- Trigger: condition to act (for example, "from 2 uses")
- Status: open | decided | done
```
